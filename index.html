Install on iPad · 添加到主屏幕
  1. Open this address in Safari while online. Sign in if prompted.
  2. Tap Share → Add to Home Screen. Keep Open as Web App on if shown, then tap Add.
  3. Open A2 Key from your Home Screen. Tap Download all courses here and wait for “30 / 30 days ready offline”.
  4. Turn on Airplane Mode and open a lesson to check the text and audio.

One online setup is required. After downloading, the lessons and recordings work offline. Browser storage can be cleared by the device; this screen checks what is still saved. Download in the installed app so its saved files are available there.
