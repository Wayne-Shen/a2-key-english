Install the app
  1. Open this course online in a browser that supports installation.
  2. On phones and tablets, look for Add to Home Screen in the browser menu or Share menu. On a computer, look for Install app in the address bar or browser menu.
  3. Open the installed app and choose Download all courses. Wait for “30 / 30 days ready offline”.
  4. Disconnect from the network and open a lesson to check the saved text and audio.

One online setup is required. Installation options vary by browser. After downloading, the lessons and recordings work offline. Browser storage can be cleared by the device; this screen checks what is still saved. Download in the installed app so its saved files are available there.
